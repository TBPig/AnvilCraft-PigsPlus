# Cauldron Output Slot

<recipe id="anvilcraft_pigsplus:cauldron_output"/>

# Function

- When attached to a <ref item="minecraft:cauldron"/>,
  - outputs finished crafted items
  - if the cauldron is full of fluid, outputs the fluid into the empty <ref item="minecraft:cauldron"/> below, if any
- When attached to a container, can eject items

# Signal Control

- Can be turned off by redstone signal
