# 炼药锅输出槽

<recipe id="anvilcraft_pigsplus:cauldron_output"/>

# 功能

- 贴在<ref item="minecraft:cauldron"/>上时，
  - 输出制作完成的物品
  - 如果炼药锅装满了流体，输出流体至下方空的<ref item="minecraft:cauldron"/>(如果有的话)
- 贴在容器上时，可以喷出物品

# 信号控制

- 可以被红石信号关闭
