# <ref item="anvilcraft_pigsplus:soulbound_campfire"/>

> 对《factorio》生物室的拙劣模仿，但模仿的是生物室

# 制作

点燃<ref item="minecraft:soul_campfire"/>时，根据周围<ref item="minecraft:weeping_vines"/>的数量，有概率将其转化为<ref item="anvilcraft_pigsplus:soulbound_campfire"/>

# 工作

- 蚕食周围 8 格内的所有作物的生长层数，每株为自己提供 0.2s 燃烧时长

# 用途

- 燃烧时为距离 4 格以内玩家提供*生命恢复II*和*生命提升V*
- 可以和<ref item="minecraft:cauldron"/>搭配，执行*灵魂蔓生*配方
- 作为营火，快速烧制食物
