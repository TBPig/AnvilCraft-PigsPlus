# 功能

- 工作范围：以自己为中心3x3x3
- 可识别工作范围内<ref item="minecraft:chiseled_bookshelf"/>上的附魔书

## 常规工作模式

- 每级附魔提供 2kW 能量
- 最大发电量：1024kW
- 不消耗附魔书

## 超频工作模式

*常规工作模式*下，附魔提供的总能量超过常规最大发电量 100kW（即达到 1124kW）后，进入*超频工作模式*

- 每级附魔提供 16kW 能量（8倍于常规工作模式）
- 最大发电量：32768kW
- 吞噬附魔书，吞噬间隔与发电量成反比，达到发电上限时间隔为 10s
