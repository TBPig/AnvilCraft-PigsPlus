# 功能

- 放在玩家的背包中即可生效，最多同时生效1个
- 如果玩家处于砧艺的电网中，持续消耗 512kW
- 持续为玩家背包中的FE物品充能 40960FE/t

> 按1kW ⇒ 80FE/t 转换能量(和本体一致，通过本体config调整)
