# Void Catalyst

<item id="anvilcraft_pigsplus:void_catalyst"/>

> Sometimes we urgently need to accelerate the decay of void matter in bulk, but the normal decay process always stops as the void density decreases. To address this, we tried using Karakuri components to stabilize a small region of high-density void, so it can accelerate the decay of surrounding void matter.
