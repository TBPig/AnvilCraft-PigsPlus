# Agent Instructions

## Source Lookup Rules

1. Prefer self-explanatory code, clear names, and small focused functions.
2. Avoid comments that merely restate what the code already says.
3. Add comments only when they explain non-obvious intent, constraints, or tradeoffs.
4. Wildcard imports such as `import package.*` are forbidden. Always use explicit imports.
5. Use CLI tools for reading project files and `rg` for searching project file names or contents.
6. Do not use IDEA MCP tools or the `workspace-agent-bridge` skill for project file lookup or content search.
7. When project source lookup cannot be satisfied locally, search source JARs under `~/.gradle/caches/`.

## Tool Preference For Other Work

For tasks other than searching or reading project files, prefer IDEA MCP tools and the `workspace-agent-bridge` skill when they provide the relevant operation, such as diagnostics, formatting, refactoring, or other IDE-aware actions.

## Language File Generation

1. English language files (`en_us.json` / `en_ud.json`) are generated by datagen from `src/main/java/dev/anvilcraft/pigsplus/data/lang/`.
2. Simplified Chinese is manually maintained at `src/main/resources/assets/anvilcraft_pigsplus/lang/zh_cn.json`. Do not generate `zh_cn.json` with datagen, otherwise it will overwrite or conflict with the manual file.
3. When adding an English key to a datagen provider, add the corresponding Chinese key to the manual `zh_cn.json` so the two key sets stay unified.
4. Do not manually edit files under `src/generated/resources/`; `runData` will overwrite them.
5. If a new UI, JEI, Jade, Ageratum, recipe, Modify, or Requirement text is added, add its English key in `LangHandler` / `JeiLang` / `RecipeLang` and its Chinese key in the manual `zh_cn.json`.

## Nullability

1. Code defaults to non-null via `package-info.java` (`@ParametersAreNonnullByDefault` / `@MethodsReturnNonnullByDefault`).
2. Any parameter, field, or return that can be null must be annotated with `@Nullable` (`org.jetbrains.annotations.Nullable`), and callers must handle the nullable result.

## Code Style

1. Prefix accesses to the current instance's own fields and calls to its own methods with `this.` (e.g. `this.progress`, `this.syncState(be)`).
