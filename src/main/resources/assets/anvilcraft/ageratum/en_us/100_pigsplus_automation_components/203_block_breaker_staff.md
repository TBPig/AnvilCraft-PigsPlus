# <ref item="anvilcraft_pigsplus:block_breaker_staff"/>

<recipe id="anvilcraft_pigsplus:block_breaker_staff"/>

# Function

Left-click a block to break it immediately and attempt to place its drops directly into your inventory.

- Has a 0.4-second cooldown after each successful break
- Harder blocks consume more durability
- Does not support Fortune or similar enchantments

# Container Mode

Container protection is enabled by default. Hold [Alt] to open the mode wheel and choose whether containers can be broken.

<tip>
When container protection is enabled, blocks with item storage capabilities and lecterns cannot be broken.
</tip>
