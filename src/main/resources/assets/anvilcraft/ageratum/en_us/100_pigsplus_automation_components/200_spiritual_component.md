# Spiritual Component

<item id="anvilcraft_pigsplus:spiritual_component"/>

<color=#888888>The machine spirit rejoices</color>  

# Obtaining

When an enchanted <ref item="anvilcraft_pigsplus:karakuri_component"/> is destroyed, each enchantment has a 25% chance to generate at most one <ref item="anvilcraft_pigsplus:spiritual_component"/>

<info>
Destroyed: using fire, explosions, or cactus to destroy item drops
</info>

<warning>
The generated spiritual component will also be destroyed, so the safest way is to use a TNT explosion that destroys item drops only once
</warning>
