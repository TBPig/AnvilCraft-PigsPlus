# <ref item="anvilcraft_pigsplus:experience_interface"/>

<recipe id="anvilcraft_pigsplus:experience_interface"/>

- Must be placed against a block that can store liquid experience to function
- If the player's level is above the specified level, extracts experience from the player and stores it as liquid experience, or vice versa
- Detection range: 5x5x5
