# 铁砧工艺：猪+

大家好！这里是大猪。《铁砧工艺：猪+》为《铁砧工艺》增添了更多方块与机器，让游戏体验更加便捷、有趣。

## 实用道具

- <ref item="anvilcraft_pigsplus:weak_resin_block"/>：更方便地捕获生物
- <ref item="anvilcraft_pigsplus:menger_sponge_staff"/>、<ref item="anvilcraft_pigsplus:menger_sponge_holy_staff"/>：大范围清理液体
- <ref item="anvilcraft_pigsplus:block_breaker_staff"/>：远程破坏方块，节省物品栏空间

## 红石元件

- <ref item="anvilcraft_pigsplus:redstone_conduit_block"/>：向 6 个方向传递红石信号
- <ref item="anvilcraft_pigsplus:memory_block_comparator"/>：无需额外方块即可使用的<ref item="anvilcraft:block_comparator"/>

## FE 能量转换

- <ref item="anvilcraft_pigsplus:adjustable_power_converter"/>：自定义 FE 与 kW 之间的能量转换量和转换方向
- <ref item="anvilcraft_pigsplus:portable_wireless_charger"/>：身处电网中即可为身上的装备充能
- <ref item="anvilcraft_pigsplus:grid_adapter"/>：将 FE 方块接入*铁砧工艺*的电网

## 自动化增强

- <ref item="anvilcraft_pigsplus:block_breaker"/>：破坏方块
- <ref item="anvilcraft_pigsplus:brass_sink"/>：无限水
- <ref item="anvilcraft_pigsplus:auto_chicken"/>：自动生产鸡蛋
- <ref item="anvilcraft_pigsplus:experience_interface"/>：便捷地存取经验
- <ref item="anvilcraft_pigsplus:wireless_transmitter"/>：无线传输物品与流体
- <ref item="anvilcraft_pigsplus:electric_enchanting_table"/>：批量附魔的理想方案
- <ref item="anvilcraft_pigsplus:void_catalyst"/>：催化虚空衰变
- <ref item="anvilcraft_pigsplus:auto_jewel_crafting_table"/>、<ref item="anvilcraft_pigsplus:auto_royal_smithing_table"/>、<ref item="anvilcraft_pigsplus:auto_royal_grindstone"/>：自动完成《铁砧工艺》中的部分配方

## 高级加工

- <ref item="anvilcraft_pigsplus:chain_smithing_table"/>：一次完成多级锻造
- <ref item="anvilcraft_pigsplus:precision_magnetic_pivot"/>、<ref item="anvilcraft_pigsplus:void_acid_bucket"/>、<ref item="anvilcraft_pigsplus:universal_redstone_component"/>：用更少的材料组装电磁学相关产品

## 材料获取方式拓展

- <ref item="anvilcraft_pigsplus:chaotic_raw_ore"/>：利用一个<ref item="anvilcraft:mineral_fountain"/>获得 8 种金属
- <ref item="anvilcraft_pigsplus:budding_echo_shard"/>：生产<ref item="minecraft:echo_shard"/>
- <ref item="anvilcraft_pigsplus:ender_seed"/>：生产<ref item="minecraft:ender_pearl"/>
