# Function

1. Can compare blocks, similar to <ref item="anvilcraft:block_comparator"/>
2. Immediately records the block state in front of it when placed
3. Afterwards, if the block in front matches the recorded memory, outputs a redstone signal
4. Can be right-clicked to switch to precise mode, same behavior as <ref item="anvilcraft:block_comparator"/>

# Reading and Writing

The memory can be read and overwritten using <ref item="anvilcraft:disk"/> or <ref item="anvilcraft:structure_disk"/>
