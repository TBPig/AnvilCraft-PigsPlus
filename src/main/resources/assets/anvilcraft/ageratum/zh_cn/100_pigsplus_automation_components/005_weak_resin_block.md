# 功能

提供更便捷的捕获方式，并具备<ref item="anvilcraft:resin_block"/>的所有功能

- 可以直接捕获中立和敌对生物，**不再需要**预先施加虚弱效果
- 生物坠落到其上时会获得 5 秒的*虚弱*效果（正常行走不会触发）
